# 🗺 خارطة طريق زهو

قاعدة: ما ننتقل لمرحلة قبل ما نختبر اللي قبلها بمجموعة تجريبية.

## ✅ المرحلة 0 — التدقيق
- [x] Python 3.10+ ، python-telegram-bot 22.8 ، aiosqlite
- [x] الإعدادات من `.env` بدون أسرار بالمستودع

## ✅ المرحلة 1 — المحرك الأساسي
- [x] التشغيل، السجلات مع إخفاء التوكن
- [x] المحلل العربي (توحيد الكتابة، أطول تطابق، رفض الجمل العادية)
- [x] قاعدة بيانات SQLite بترحيلات مرقمة وقفل كتابة ومعاملات ذرية
- [x] معالجة أخطاء مركزية + تنبيه المطور
- [x] قائمة أوامر تفاعلية بالأزرار حسب الرتبة
- [x] مركز المالك (إحصائيات، صيانة، سجل العمليات، المجموعات)
- [x] تتبع المجموعات (إضافة/طرد/تحويل لمجموعة خارقة)
- [x] عداد الرسائل (مجمّع، يُكتب كل دقيقة)

## ✅ المرحلة 2 — الرتب والصلاحيات
- [x] 8 رتب + المطور، صلاحيات مركزية
- [x] مشرفي تيليجرام = أدمن تلقائياً، المنشئ محمي
- [x] رفع/تنزيل بالرد أو اليوزر أو الايدي، قوائم الطاقم
- [x] منع التصعيد (رفع النفس، رتبة مساوية/أعلى)
- [x] سجل تدقيق لكل تغيير

## ✅ المرحلة 3 — العقوبات
- [x] حظر، طرد، كتم، تقييد (دائم أو مؤقت ينتهي تلقائياً: 10د، 2س، 3ي، 1ا)
- [x] سبب اختياري يظهر بالرسالة وينحفظ بالسجل
- [x] تحذيرات بحد أقصى قابل للتعديل (2–10) وعقوبة تلقائية (كتم/طرد/حظر)
- [x] قوائم المحظورين/المكتومين/المقيدين مع الوقت المتبقي، وسجل عقوبات لكل عضو
- [x] فحص صلاحيات البوت الفعلية قبل التنفيذ مع توضيح سبب الفشل
- [x] زر تراجع على رسالة العقوبة (بنفس قواعد الرتب)
- [x] مزامنة إذا رفع مشرف العقوبة يدوياً من تيليجرام
- [x] شخصية زهو الجديدة: بنت راقية ومهذبة مع عناوين مزخرفة

## ✅ المرحلة 4 — الحماية
- [x] مكافحة الإغراق (7 رسائل/5 ثواني ← كتم 10 دقائق) والرسائل المكررة
- [x] الروابط (مع قائمة مواقع مسموحة + رابط المجموعة مسموح دائماً)، التوجيه، المنشن الجماعي
- [x] طرد البوتات اللي يضيفها غير الأدمن
- [x] تحقق الأعضاء الجدد بزر (3 دقائق، ويتحمل إعادة تشغيل البوت)
- [x] لوحة أزرار + مستويات جاهزة (خفيف / متوسط / صارم / مخصص)
- [x] عقوبة متدرجة: حذف + تنبيه (ينحذف تلقائياً) ← بعد 3 مخالفات كتم ساعة
- [x] المميز فما فوق مستثنى، وسجل حماية

## ✅ المرحلة 5 — إعدادات المجموعة
- [x] لوحة «الإعدادات» الشاملة (ترحيب، توديع، التحذيرات، تنقل للأقفال والحماية مع رجوع)
- [x] 14 قفل: الصور، الفيديو، المتحركات، الملصقات، البصمات، الصوتيات، الملفات، الجهات، المواقع،
      الاستفتاءات، الإشعارات، الروابط، التوجيه، الدردشة (صلاحيات تيليجرام) + لوحة أزرار + قفل/فتح الكل
- [x] الترحيب والتوديع بقوالب ومتغيرات ومعاينة، الترحيب بعد التحقق، حذف الترحيب القديم تلقائياً
- [x] القوانين (مع زر بالترحيب)، الرابط (تلقائي أو مخصص)، الإحصائيات

## ✅ إضافة — قفل السب + اللهجة العراقية
- [x] كل كلام زهو بلهجة عراقية خالصة + فصحى، والأوامر والخيارات فصحى
- [x] كاشف سب ذكي: يلگى السب بنص الكليشة، ويكشف التمويه (تكرار حروف، رموز، حروف مفرقة، گ/چ)
- [x] بدون إيجابيات كاذبة (عكس، كسرة، زبون، بعير، كوادر...) — مختبر بالأمثلة
- [x] ثلاث أوضاع: `قفل السب` (مسح) ، `قفل السب بالكتم` ، `قفل السب بالحظر` — من أول مرة
- [x] `السب المحذوف`: منو سب، الكلمة، ورسالته الكاملة (30 يوم)
- [x] قاموس خاص لكل مجموعة (إضافة/سماح)، وفحص الرسائل المعدلة

## ✅ إضافة — الردود والاختصارات
- [x] التقييد = مشاهدة فقط (بلا كتابة ولا رياكت ولا أي تفاعل)، والكتم يسمح بالرياكت بس
- [x] قفل الرياكت (يشيل تفاعل غير المستثنين)، و«فتح التقييد/الكتم/الحظر»
- [x] اختصارات الأوامر بخطوات: `اضف امر` (قديم ← جديد)، `حذف امر`، `الاوامر المضافة`
- [x] الردود العادية والمميزة بخطوات (حتى 10 ردود، `تم` / `حذف`)، كل أنواع الرسائل
- [x] الرد المميز ينرسل حتى لو الكلمة بنص كليشة
