- كل الأوامر **بدون /** وتتحمل اختلاف الكتابة (أ/ا، ة/ه، التشكيل، التطويل).
- الاستهداف: **بالرد** على رسالة الشخص، أو **@يوزره**، أو **ايديه**.
- العقوبات تقبل مدة وسبب: `كتم @user 30د سبام` — الوحدات: `د` دقائق، `س` ساعات، `ي` أيام، `ا` أسابيع.
- قائمة أوامر **تفاعلية بالأزرار**، تعرض لكل شخص الأوامر المسموحة لرتبته فقط، وما أحد يكدر يضغط على قائمة غيره.

### 🔐 الأمان
- التوكن ما ينكتب بالكود، ويُخفى تلقائياً من السجلات.
- صلاحيات مركزية: ما أحد يرفع نفسه، ولا يرفع لرتبة تساويه أو أعلى، ولا يلمس رتبة أعلى منه.
- المنشئ ومطور البوت رتب **محمية** ما تتغير.
- كل عملية إدارية تنسجل بسجل تدقيق (المنفذ، الهدف، الوقت، النتيجة).
- حماية من الإغراق بالأوامر والأزرار، ووضع صيانة، ورفض أوامر المشرف المخفي.
- لا تظهر أي أخطاء تقنية للأعضاء؛ المطور يوصله تنبيه مختصر.

## 🚀 التشغيل خطوة بخطوة (بدون خبرة برمجة)

### 1) جهّز البوت من @BotFather
1. افتح [@BotFather](https://t.me/BotFather) واكتب `/newbot`، سمّه **زهو** واختار له يوزر.
2. انسخ **التوكن** واحفظه عندك (لا ترسله لأي أحد).
3. **مهم جداً:** اكتب `/setprivacy` ← اختار البوت ← **Disable**
   (بدون هذا البوت ما يشوف الأوامر العربية بالمجموعات).
4. اختياري: `/setjoingroups` ← Enable.

### 2) اعرف الايدي مالتك
افتح [@userinfobot](https://t.me/userinfobot) وانسخ الرقم (Id).

### 3) الرفع على استضافة FadeHost
لوحة الاستضافة على الأغلب **Pterodactyl**. الخطوات:

1. أنشئ سيرفر من نوع **Python**، ويُفضّل إصدار **3.11 أو أحدث**.
2. من **Startup** (أو الإعدادات):
   - `App py file` / `BOT PY FILE` ← اكتب: `main.py`
   - `Requirements file` ← `requirements.txt`
   - إذا موجود **Git Repo Address**: حط رابط المستودع `https://github.com/queZah-web/Bot` واختار الفرع.
     إذا ماكو، ارفع الملفات يدوياً من **Files** (ملف ZIP ثم Unarchive).
3. من **Files** سوِّ ملف جديد اسمه **`.env`** واكتب بيه:
   ```
   BOT_TOKEN=التوكن_مالتك
   OWNER_ID=الايدي_مالتك
   ```
4. اضغط **Start**. إذا شفت بالـ Console سطر `زهو 0.1.0 اشتغل باسم @...` فكل شي تمام ✅
5. افتح البوت بالخاص واكتب `/start`.

> 💡 قاعدة البيانات تنحفظ بمجلد `data/` وتبقى بعد إعادة التشغيل. لا تحذفه.

### ⚠️ إذا طلع «ما كدرت أوصل لسيرفر تيليجرام»
شركة الاتصالات ممكن تحجب `api.telegram.org`. شغّل **VPN** وأعد التشغيل،
أو أضف بروكسي بملف الإعدادات: `PROXY_URL=http://IP:PORT`

### 4) بالمجموعة
ضيف البوت، ارفعه **مشرف** (حذف رسائل + حظر + دعوة + تثبيت)، واكتب `الاوامر`.

## 🧪 للمطورين

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env   # واملأ القيم
python main.py         # تشغيل
python -m pytest -q    # الاختبارات
```

### هيكل المشروع
```
main.py                 نقطة التشغيل
zhoo/
  app.py                بناء التطبيق وربط المعالجات
  config.py             تحميل الإعدادات (.env / متغيرات البيئة)
  core/                 المحلل العربي، الرتب، الصلاحيات، النصوص، التتبع، محدد المعدل
  database/             الاتصال + ترحيلات مرقمة (migrations/)
  repositories/         طبقة الوصول للبيانات
  handlers/             استقبال تحديثات تيليجرام (رسائل، أزرار، عضوية، أخطاء)
  keyboards/            الأقسام والأزرار التفاعلية
  systems/              الأنظمة: general، ranks، owner (والقادم: punish، protect...)
tests/                  اختبارات الوحدات والتدفق الكامل
```

**إضافة أمر جديد** = دالة وحدة بأي ملف داخل `systems/` مع المزخرف `@registry.command(...)`، وتظهر تلقائياً بقائمة الأزرار.
كل النصوص بـ `zhoo/core/texts.py` حتى تعدلها بسهولة.
